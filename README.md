# 8-Queens & Bishops Problem Visualizer 👑

An interactive visualization tool for the classic **8-Queens/Bishops problem**, developed with **Python** and **PyQt6** as a semester project for the Artificial Intelligence course.

## 📝 Description
The application solves and visualizes the problem of placing 8 pieces on an $8 \times 8$ chessboard such that no two pieces threaten each other, following the rules of chess movement for queens and bishops. It features a step-by-step animation of the solving process and maintains a historical gallery of discovered solutions.

## ✨ Features
- **Real-time Animation**: Visualizes threat checks for each column before placing a piece.
- **Solution History**: Automatically saves successful configurations in a sidebar gallery with mini-thumbnails.
- **Interactive UI**: Ability to restart the animation and track solving statistics in real-time.
- **Visual Feedback**: Displays diagonal threat lines and highlights "attacked" squares.
